## 2026-05-14 - Route Hardening and Information Leakage Prevention
**Vulnerability:** Multiple security gaps in `backend/src/routes/projects.ts`, including BOLA (Broken Object Level Authorization) on the AI insights endpoint, Mass Assignment in document creation, and Information Leakage via raw `error.message` in 500 responses.
**Learning:** Project-scoped routes often lack consistent middleware application (e.g., `requireProjectRole` was missing on some AI routes), and the use of spread operators (`...req.body`) in model instantiation created mass assignment risks. Standardizing error handling across an entire route file is necessary to prevent leaking database or environment details.
**Prevention:** Always apply role-based access control (RBAC) to all project-scoped routes. Use explicit field whitelisting instead of object spreading when creating or updating models. Implement a global or file-level catch-all that logs errors and returns generic messages to the client.
