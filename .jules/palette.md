
## 2026-07-02 - Modal Accessibility Standard
**Learning:** Modals must support the "Standard Modal Trio" (Escape key, backdrop click-to-close, and visible close button) plus proper ARIA labeling to be considered accessible and user-friendly in this application.
**Action:** Always implement the Standard Modal Trio using a useEffect for Escape and stopPropagation for backdrop clicks when creating or enhancing modals.
