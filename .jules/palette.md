## 2026-07-28 - Login Accessibility and Convenience
**Learning:** Hardcoded demo credentials in UI text are better served as interactive "Quick Login" buttons to improve both UX and developer velocity during testing. Password visibility toggles and proper label linking are foundational accessibility requirements that are often overlooked in early prototypes.
**Action:** Always check if login forms have linked labels (htmlFor/id), password toggles, and if demo accounts can be made interactive.
