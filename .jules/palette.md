## 2026-06-12 - Interactive Quick Login and Accessibility Baseline
**Learning:** For demo-heavy construction PM tools, providing "Quick Login" buttons significantly improves the evaluation experience. Ensuring accessibility baseline (linked labels, password toggle, focus states) from the start prevents UX regressions.
**Action:** Always link labels with `id`/`htmlFor`, add `aria-label` to icon-only buttons, and provide demo shortcuts for authentication flows.
