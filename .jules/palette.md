# Palette's UX & Accessibility Journal

## 2026-06-29 - Interactive Demo Credentials
**Learning:** Providing demo credentials as plain text requires users to manually copy/paste or type them, increasing friction during the onboarding/exploration phase. Interactive badges that auto-fill credentials improve the first-time user experience.
**Action:** Always consider making demo credentials interactive buttons in login/onboarding flows to reduce cognitive load and friction.
